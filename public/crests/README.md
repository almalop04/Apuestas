# Carpeta de Escudos Personalizados (/public/crests)

Aquí puedes colocar cualquier imagen de escudo que desees para que aparezca automáticamente en la web con calidad perfecta.

### ¿Cómo funciona?
1. Guarda la imagen en formato `.png` dentro de esta carpeta (`public/crests/`).
2. Ponle de nombre el nombre del equipo en minúsculas y separado por guiones.
   - Ejemplo para el Real Madrid: `real-madrid.png`
   - Ejemplo para el CD Covadonga: `cd-covadonga.png` o `covadonga.png`
   - Ejemplo para el CD Coria: `cd-coria.png` o `coria.png`
3. ¡Listo! La web detectará la imagen y la mostrará inmediatamente sin tener que tocar una sola línea de código.
